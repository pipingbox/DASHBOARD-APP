IMPORTANTE:
- Usa los valores reales de ASME B36.10M Table 1.
- STD = SCH 40 para NPS <= 10", STD = 3/8" WT para NPS >= 12".
- XS = SCH 80 para NPS <= 8".
- Calcula id = od - 2*wt.
- Calcula weight_kg_per_m = 0.02466 * (od_mm - wt_mm) * wt_mm.
- Calcula weight_lb_per_ft = weight_kg_per_m * 0.6720.
- NO inventes valores. Si un schedule no existe para un NPS, NO lo incluyas.
