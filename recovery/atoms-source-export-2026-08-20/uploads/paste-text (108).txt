### Flujo del examen:

PANTALLA 1: INTRO (pre-examen)
- Titulo: "VCA Practice Exam - {B-VCA | VOL-VCA}"
- Card informativa:
  - Numero de preguntas: 40 (B-VCA) o 70 (VOL-VCA)
  - Tiempo limite: 60 min (B-VCA) o 105 min (VOL-VCA)
  - Puntuacion minima: 28/40 (B-VCA) o 49/70 (VOL-VCA)
  - Formato: Multiple choice A/B/C
  - Reglas: Una sola respuesta correcta por pregunta. No se puede volver atras en el examen oficial.
- Checkbox: "Entiendo las reglas del examen"
- Boton "Iniciar examen" (disabled hasta marcar checkbox)
- Al clickar: empieza el timer y se muestra la pantalla de examen

PANTALLA 2: EXAMEN (activo)
- HEADER fijo:
  - Timer cuenta atras (mm:ss) en grande, cambia a rojo si quedan <5 min
  - Progress: "Pregunta X de Y"
  - Barra de progreso
  - Boton "Finalizar examen" (con confirmacion Dialog)
- CUERPO:
  - Una pregunta a la vez (no todas juntas como en el quiz de modulo)
  - Texto de pregunta grande
  - RadioGroup con 3 opciones A/B/C
  - Boton "Siguiente" (disabled hasta seleccionar una opcion)
  - Boton "Anterior" (volver a pregunta previa, permite cambiar respuesta)
  - En la pregunta final: boton "Finalizar y ver resultados"
- NAVEGACION:
  - Grid de numeros 1-40 (o 1-70) en la parte inferior o lateral
  - Numeros respondidos en amber, no respondidos en gris
  - Click en numero salta a esa pregunta
- Timer:
  - useEffect con setInterval cada 1 segundo
  - Cuando llega a 00:00: auto-submit
  - Avisar cuando queden 5 minutos (toast warning)

PANTALLA 3: RESULTADOS (post-examen)
- Card grande de resultado:
  - APROBADO (verde) o SUSPENSO (rojo)
  - Score: X/Y correctas (Z%)
  - Tiempo usado: mm:ss
  - Tipo de examen
  - Fecha
- Stats:
  - Tiempo usado vs limite
  - Porcentaje de acierto
  - Preguntas por categoria (opcional, si hay tiempo)
- Boton "Revisar respuestas" que expande todas las preguntas con:
  - Tu respuesta (correcta/incorrecta)
  - Respuesta correcta
  - Explicacion
- Boton "Nuevo examen" (reinicia)
- Boton "Volver a Academy"
- Guardar resultado en Supabase tabla app_14da0f1941_academy_mock_exams

### Timer implementation

useEffect(() => {
  if (phase !== 'exam') return;
  const interval = setInterval(() => {
    setTimeLeft(prev => {
      if (prev <= 1) {
        clearInterval(interval);
        handleSubmit();
        return 0;
      }
      return prev - 1;
    });
  }, 1000);
  return () => clearInterval(interval);
}, [phase]);

Formato del timer:
const formatTime = (sec: number) => {
  const m = Math.floor(sec / 60);
  const s = sec % 60;
  return `${String(m).padStart(2, '0')}:${String(s).padStart(2, '0')}`;
};

### Guardado en Supabase

const handleSubmit = async () => {
  const correct = questions.filter(q => answers[q.id] === q.correctAnswer).length;
  const total = questions.length;
  const percentage = Math.round((correct / total) * 100);
  const passed = correct >= (examType === 'bvca' ? 28 : 49);
  const duration = Math.floor((Date.now() - startTimeRef.current) / 1000);

  // Guardar
  try {
    if (user) {
      await supabase.from('app_14da0f1941_academy_mock_exams').insert({
        user_id: user.id,
        exam_type: examType,
        total_questions: total,
        correct_answers: correct,
        passed,
        duration_seconds: duration,
        completed_at: new Date().toISOString(),
      });
    }
  } catch (e) {
    console.warn('Could not save exam result:', e);
  }

  setPhase('results');
};
