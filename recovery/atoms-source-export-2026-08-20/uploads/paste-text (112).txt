## LO QUE HAY QUE MEJORAR (PROBLEMAS ACTUALES)

### Problema 1: SVG demasiado simplista
El SVG actual de cada tipo de flange (WN/SO/BL) es un esquema con 4-5 líneas y un rectángulo.
Parece un placeholder, no un drawing técnico.

Solución: Rediseñar los 3 SVGs (WN, SO, BL) como drawings técnicos profesionales con:
- Vista lateral realista del flange con proporciones correctas (usar spec.od, spec.flangeThickness, spec.boltCircleDiameter, spec.hubLength, spec.pipeOD para escalar)
- Hub taper real para WN (Weld Neck) — el cono de transición entre pipe y flange
- Weld prep visible (bevel) en WN
- Raised face visible (RF) — la cara elevada donde asienta la junta
- Bolt holes representados correctamente (número real de spec.numBolts, distribución en círculo)
- Hatching en blind flange (BL) para indicar sólido
- Pipe stub a ambos lados con OD correcto

### Problema 2: Faltan cotas (dimension lines)
El SVG actual NO tiene dimension lines con flechas. Solo badges con números sueltos.

Solución: Añadir sistema de cotas técnico profesional:
- Dimension lines: líneas horizontales/verticales con flechas en los extremos
- Extension lines: líneas cortas perpendiculares desde el objeto hasta la dimension line
- Labels: el valor numérico encima de la dimension line (ej: "Ø 318 mm")
- Cotas a mostrar en el SVG del modal:
  - Ø Outside Diameter (OD) — horizontal sobre el flange
  - Flange thickness — vertical a la derecha
  - Bolt circle diameter (BCD) — horizontal con línea de centro punteada
  - Hub length (solo WN) — vertical
  - Pipe OD — horizontal sobre el pipe stub
  - Raised face height — pequeña cota vertical
  - Bolt hole Ø — cota en un agujero
- Toggles de visibilidad (como ElbowCut):
  - showDimensions — mostrar/ocultar todas las cotas
  - showCenter — mostrar/ocultar línea de centro
  - showBoltHoles — mostrar/ocultar agujeros perno
  - showFill — mostrar/ocultar relleno

### Problema 3: Modal de detalle mejorable
El modal actual muestra datos en DimBox y DimRow pero el SVG es el mismo simplista de la card.

Solución: El modal debe tener:
- SVG GRANDE (400×300 mínimo) con TODAS las cotas visibles
- Vista isométrica o lateral con proporciones reales escaladas
- Sistema de cotas completo (dimension lines + extension lines + labels)
- Toggles de visibilidad arriba del SVG
- Layout en 2 columnas: SVG grande a la izquierda, tabla de dimensiones a la derecha
- Sección de cross-linking (gasket + bolts + torque) debajo — MANTENER TAL CUAL, está bien
- Tab de "Cross-Link" separado del tab "Dimensions" para no saturar

### Problema 4: Cards de la grid demasiado simples
La card actual tiene un SVG mini de 100×80 que no se entiende.

Solución: Card más rica visualmente:
- SVG mini (120×80) pero con proporciones correctas del flange
- 3-4 dimensiones clave overlaid como labels pequeños (OD, BCD, thickness)
- Badge de tipo (WN/SO/BL) más visible
- Al hover, mostrar un preview de las cotas principales
- Mantener peso, nº pernos, OD en la parte inferior

## DATOS DISPONIBLES EN FlangeSpec (NO cambiar)

interface FlangeSpec {
  type: 'WN' | 'SO' | 'BL';
  typeLabel: string;           // 'Weld Neck' | 'Slip-On' | 'Blind'
  pressureClass: '150#'|'300#'|'600#'|'900#'|'1500#';
  facing: 'RF' | 'RTJ';
  nps: string;                 // '6"'
  pipeOD: number;              // 168.3 mm
  od: number;                  // 318 mm (Outside Diameter)
  flangeThickness: number;     // 31.8 mm
  boltCircleDiameter: number;  // 269.9 mm
  numBolts: number;            // 12
  boltHoleDiameter: number;    // 22.3 mm
  boltSize: string;            // '3/4"'
  studLength: number;          // 150 mm
  hubDiameterEnd?: number;     // 200.3 mm (solo WN)
  hubDiameterBase?: number;    // 241.4 mm (solo WN)
  hubLength?: number;          // 33.4 mm (solo WN)
  boreDiameter?: number;       // 168.3 mm (WN/SO, no BL)
  weight: number;              // 13.5 kg
  gasketOD: number;
  gasketID: number;
  gasketType: string;
}
