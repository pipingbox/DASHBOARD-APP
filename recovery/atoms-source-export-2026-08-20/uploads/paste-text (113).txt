## TAREA 3: Refactorizar Flange Library a flujo guiado

**Archivo:** `src/tools/flange-library/FlangeLibrary.tsx`

### Problema actual
La grid muestra TODOS los specs (270 cards) antes de filtrar. El usuario se ahoga en thumbnails.

### Solución: flujo guiado de 5 pasos
El usuario NO ve cards hasta que selecciona los 4 filtros. El flujo es:

```
Paso 1: Standard     → solo ASME B16.5 disponible ahora (mostrar como badge, no selector)
Paso 2: Type         → WN | SO | BL  (3 botones grandes)
Paso 3: Class        → 150# | 300# | 400# | 600# | 900# | 1500# | 2500#  (botones, solo los que tengan specs para ese type)
Paso 4: NPS          → 1/2" | 3/4" | 1" | ... | 24"  (solo los que existan para type+class)
Paso 5: RESULT       → SVG grande + cotas + tabla + cross-links
```

### UX del flujo guiado
- Cada paso se habilita solo cuando el anterior está seleccionado (estilo wizard).
- Los pasos 3 y 4 muestran SOLO las opciones que tienen specs reales (filtra `FLANGE_SPECS` por type, luego por class, luego por nps).
- Cuando llegas al paso 5, se muestra UN solo resultado (el spec exacto) con el SVG grande.
- Botón "Back" para cambiar de paso sin perder los ya seleccionados.
- Mantener la barra de búsqueda libre (TechnicalSearch) como alternativa al wizard — si el usuario busca "6 inch WN 300#", se salta el wizard y va directo al resultado.

### Estructura del componente refactorizado

```typescript
export function FlangeLibrary({ user }) {

  const [step, setStep] = useState<1|2|3|4|5>(1);

  const [selectedNps, setSelectedNps] = useState<string | null>(null);

  // Compute available options at each step (filter FLANGE_SPECS)

    ? [...new Set(FLANGE_SPECS.filter(s => s.type === selectedType).map(s => s.pressureClass))]

    ? [...new Set(FLANGE_SPECS.filter(s => s.type === selectedType && s.pressureClass === selectedClass).map(s => s.nps))]
    : [];

  // Result spec

    ? FLANGE_SPECS.find(s => s.type === selectedType && s.pressureClass === selectedClass && s.nps === selectedNps) ?? null
    : null;

  // ... render wizard steps + result
}
```

## TAREA 4: Rediseñar SVG con dibujos técnicos profesionales + cotas

**Archivo:** `src/tools/flange-library/FlangeLibrary.tsx` (dentro del modal de resultado)

### Diseño de referencia
`src/tools/elbow-cut/ElbowCut.tsx` — el cliente lo ama. Cópiale el PATRÓN VISUAL:
- Controles de visibilidad (checkboxes) para toggle de cotas/centro/agujeros/relleno
- SVG grande con viewBox, paths coloreados, labels de dimensiones inline
- Paleta: cyan `#22d3ee`, naranja `#f97316`, blanco punteado, ámbar `#f59e0b`, rojo `#ef4444`
- Bordes `rounded-sm`, fondos `#0d0d0d`, bordes `border-zinc-800`

### Problemas actuales del SVG
El SVG actual de cada tipo de flange (WN/SO/BL) es un esquema con 4-5 líneas y un rectángulo. Parece un placeholder, no un drawing técnico.

### Solución: rediseñar los 3 SVGs (WN, SO, BL) como drawings técnicos profesionales

**Vista lateral realista del flange** con proporciones correctas (usar `spec.od`, `spec.flangeThickness`, `spec.boltCircleDiameter`, `spec.hubLength`, `spec.pipeOD` para escalar):
- Hub taper real para WN (Weld Neck) — el cono de transición entre pipe y flange
- Weld prep visible (bevel) en WN
- Raised face visible (RF) — la cara elevada donde asienta la junta
- Bolt holes representados correctamente (número real de `spec.numBolts`, distribución en círculo)
- Hatching en blind flange (BL) para indicar sólido
- Pipe stub a ambos lados con OD correcto

### Sistema de cotas técnico profesional
- **Dimension lines**: líneas horizontales/verticales con flechas en ambos extremos
- **Extension lines**: líneas cortas perpendiculares desde el objeto hasta la dimension line
- **Labels**: el valor numérico encima de la dimension line (ej: "Ø 318 mm")

Cotas a mostrar en el SVG del modal:
- Ø Outside Diameter (OD) — horizontal sobre el flange
- Flange thickness — vertical a la derecha
- Bolt circle diameter (BCD) — horizontal con línea de centro punteada
- Hub length (solo WN) — vertical
- Pipe OD — horizontal sobre el pipe stub
- Raised face height — pequeña cota vertical
- Bolt hole Ø — cota en un agujero

### Toggles de visibilidad (como ElbowCut)
```typescript
const [showDimensions, setShowDimensions] = useState(true);
```
