# Project Summary
PipingBox is an industrial hiring platform where companies publish open job offers and workers browse and apply to real positions stored in Supabase. The product emphasizes secure, Supabase-backed job discovery with attribute filters, an application workflow that avoids duplicate submissions, and a companion companies page that surfaces Supabase-derived workforce/company metrics.

# Project Module Description
- Jobs (Listings): Supabase-backed job search, filtering, and an apply flow for authenticated users that prevents duplicate applications.
- Job Filters: UI to refine jobs by attributes (e.g., country/discipline/work type/contract type/urgent) while reflecting the active filter state.
- Job Cards: Job detail rendering (title, company, location, type, salary, remote/category badges) and Apply states (idle/applying/applied).
- Companies Overview: Supabase query-based metrics (e.g., counts of active companies, open positions, available workers, active countries) with workforce-request calls to action.
- Additional Routes Recovery (Atoms): Includes password recovery, account/company/legal pages required by production routing:
  - /forgot-password, /reset-password
  - /privacy, /terms
  - /company/billing, /company/settings, /company/documentation

# File Description Inventory
- app/frontend/src/lib/jobs/static-data.ts: Shared job helper functions/constants and formatting/mapping utilities; explicitly no fabricated job listings.
- app/frontend/src/hooks/useJobs.ts: Fetches and filters jobs from Supabase and submits applications; removes any logic that fuses in static/featured data.
- app/frontend/src/pages/Jobs.tsx: Page that renders Supabase-driven job results with filtering/search.
- app/frontend/src/components/jobs/JobCard.tsx: Displays job details and manages Apply button states.
- app/frontend/src/pages/Companies.tsx: Queries Supabase for company/job/worker/country metrics; no hardcoded activity/metrics.
- app/frontend/src/pages/ForgotPassword.tsx: Source for /forgot-password route.
- app/frontend/src/pages/ResetPassword.tsx: Source for /reset-password route.
- app/frontend/src/pages/Privacy.tsx: Source for /privacy route.
- app/frontend/src/pages/Terms.tsx: Source for /terms route.
- app/frontend/src/pages/company/CompanyBilling.tsx: Source for /company/billing route.
- app/frontend/src/pages/company/CompanySettings.tsx: Source for /company/settings route.
- app/frontend/src/pages/company/CompanyDocumentation.tsx: Source for /company/documentation route.
- app/frontend/src/components/layout/AppShell.tsx: Shell/navigation entries including links to /privacy and /terms.
- app/frontend/src/lib/roles.ts: Authorization used by protected company routes.
- app/frontend/src/i18n/locales/*.json: Translation updates, including removing content tied to previously removed fabricated feed/activity references.
